# emakefun-midi MakeCode扩展

MIDI数字音乐模块是一款基于General MIDI 2.0标准的专业音乐合成模块，具备完整的MIDI音频处理与输出能力。该模块内置丰富的波表音色库，包含128种通用MIDI音色和128种扩展音色，以及数十种专业打击乐音色。

## 功能特性

### 核心功能

- **初始化MIDI**: 配置串口引脚进行MIDI通信
- **音符播放**: 支持16个MIDI通道播放音符，包含完整的音高范围（C-1到G9）
- **打击乐**: 通道9专用于打击乐，提供丰富的打击乐音色
- **音色选择**: 支持256种音色（128种标准音色 + 128种扩展音色）
- **音量控制**: 单通道音量和全局音量调节
- **速度设置**: 可调节演奏速度（1-300 BPM）
- **音频效果**: 混响和合唱效果
- **MIDI重置**: 一键重置所有MIDI参数

### 音色库

包含钢琴、电子琴、八音盒、颤音琴、马林巴、管风琴、口琴、吉他、贝斯、小提琴、大提琴、长号、萨克斯、单簧管、长笛、陶笛、古筝、唢呐、钢鼓等多种乐器音色。

### 打击乐音色

包含军鼓、通鼓、边击、踩镲、地通鼓、响棒、木鱼、牛铃、三角铁、邦戈鼓、康加鼓、沙槌、刮瓜等多种打击乐音色。

## 安装方法

1. 打开MakeCode for micro:bit，网址：https://makecode.microbit.org/
2. 点击工具栏中的"扩展"
3. 搜索"emakefun-midi"并点击"导入"
4. 扩展将被添加到您的项目中

## 快速开始

### 基本使用步骤

1. **初始化MIDI引脚**
   ```
   初始MIDI引脚 P0
   ```

2. **设置通道乐器**
   ```
   将通道 0 的乐器设为 #0 钢琴
   ```

3. **播放音符**
   ```
   通道 0 演奏音符 C4 1/4节拍
   ```

4. **打击乐演奏**
   ```
   击打 D2 军鼓音色1 力度 100
   ```

## API 参考

### 初始化

- `初始MIDI引脚 [tx]` - 初始化MIDI通信引脚

### 音符演奏

- `通道 [channel] 演奏音符 [note] [duration]` - 在指定通道上演奏音符
- `击打 [note] 力度 [velocity]` - 演奏打击乐音符
- `休止 [duration]` - 休止指定时长

### 音色设置

- `将通道 [channel] 的乐器设为 [timbre]` - 设置标准音色
- `将通道 [channel] 的乐器设为扩展音色 #[timbre]` - 设置扩展音色
- `将打击乐音色类型设为 [type]` - 设置打击乐音色类型

### 音量控制

- `将通道 [channel] 音量设为 [volume] %` - 设置单通道音量
- `将所有通道音量设为 [volume] %` - 设置全局音量

### 速度设置

- `将演奏速度设为 [tempo] BPM` - 设置演奏速度（1-300）

### 音频效果

- `将通道 [channel] 混音效果 [type] 音量设为 [volume] % 延迟反馈 [feedback] %` - 设置混响效果
- `将通道 [channel] 合唱效果 [type] 音量设为 [volume] % 延迟 [delay] 毫秒` - 设置合唱效果

### 其他

- `MIDI重置` - 重置所有MIDI设置

## 硬件连接

将MIDI模块的TX引脚连接到micro:bit的指定GPIO引脚（默认P0），确保波特率设置为31250。
